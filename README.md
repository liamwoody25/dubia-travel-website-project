# Dubai Travel Website

### project description
the purpose of this Dubai travel website is to help the users find the information about places to stay and to also look for things to do in Dubai

### Technologies:
+ semantic HTML5,
+ CSS3 Styling transitions,
+ JavaScript

### Features

+ Built a hamburger menu to display the navigation links for a mobile-first approach.
+ added transitions to the cards to make them interactive.
+ added interactive accordions with transitions and javascript.

### what I learned 

I built this project so I could practice building a hamburger menu for a mobile-first approach. I also learned how to use css transitions and how to build with them
